## Warm Field Manual architecture

The site is intentionally static and dependency-free: HTML, CSS, and vanilla JavaScript served by GitHub Pages. There is no backend, database, account system, newsletter gate, third-party form service, or analytics SDK.

The OUTSMART AI AT WORK Companion Toolkit includes:

- a private 60-Second Job Defense Checkup
- Career Exposure Number calculator
- Hidden Replacement Bill calculator
- Package Defense Comparison
- Threat Signal Scorecard
- Exception Ledger
- Decision Rights Map
- Sponsor Map
- AI Value Capture Log
- One-Page Compensation Brief
- eight copy-ready AI prompts
- printable 72-Hour Defense Plan
- printable 90-Day Operating Plan

## Privacy model

Checkup answers and calculator inputs are processed in the browser. The site does not require a name or email and does not submit worksheet content to a remote service.

When a reader chooses **Save on this device**, worksheet values are stored only in browser `localStorage` under keys prefixed with `rourke:outsmart:`. That storage is local to the current browser/profile/device and can be removed with the worksheet **Clear** control or by clearing browser site data.

Readers should not enter confidential employer information on shared devices or into external AI services that their organization has not approved.

## Printing

Major Toolkit tools are self-contained worksheets. Each supports US Letter printing without site navigation or unrelated sections. Where useful, readers can choose between a blank worksheet and a copy containing their current answers.
